Frequently asked questions

Camera, privacy, and how the tool works

Is Quiet Zone actually free?

Yes. There's no paid tier, no usage limit, and no account required to scan or generate codes.

Do you store the codes I scan or generate?

No. Everything happens locally in your browser. Camera frames, uploaded images, and generated codes are never uploaded or stored on a server — see the Privacy Policy for the full explanation.

Why does the site ask for camera access?

Only to show a live preview so you can point at a code. Your browser handles the permission directly; Quiet Zone reads video frames locally to look for a code and never transmits them anywhere.

The camera won't turn on — what do I do?

Camera access needs a secure connection (HTTPS) and browser permission. If it's blocked, check your browser's site settings for a denied camera permission, or use the "Upload image" option instead, which works from any photo of a code.

What's the difference between the error correction levels?

Low, Medium, Quartile, and High control how much of a generated code can be damaged, smudged, or obscured and still scan correctly. Higher levels are more forgiving but make the code visually denser. Medium is a good default for most uses; use High if the code will be printed small or somewhere it might get scratched, like a sticker.

Is there a limit to how much text I can put in a code?

QR codes can hold a few thousand characters, but longer text produces a denser, harder-to-scan code. For links and short messages you won't notice a limit; for long text, a higher error correction level or a shorter link works better.

Can I use this without an internet connection?

Once the page has loaded, scanning and generating both run locally, so a spotty connection won't interrupt an in-progress scan. Loading the page itself still needs a connection the first time.

Is it safe to scan a code I found somewhere in public?

Quiet Zone shows you the decoded destination before it opens anything, so you can read the link first instead of being redirected automatically. That said, no scanner can tell you whether a destination itself is safe — treat an unfamiliar link the same way you would if someone texted it to you.
